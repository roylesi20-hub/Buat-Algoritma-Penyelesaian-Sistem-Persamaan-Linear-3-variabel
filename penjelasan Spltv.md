PENJELASAN PROGRAM SPLTV

1. Program ini digunakan untuk menyelesaikan
   Sistem Persamaan Linear Tiga Variabel.

2. Library NumPy digunakan untuk membantu
   operasi perhitungan matriks.

3. Matriks A berisi koefisien variabel x, y, z.

4. Matriks B berisi nilai konstanta.

5. Matriks augmented menggabungkan A dan B.

6. Eliminasi Gauss digunakan untuk mengubah
   matriks menjadi bentuk segitiga atas.

7. Substitusi mundur digunakan untuk mencari
   nilai x, y, dan z.

8. Hasil program ditampilkan menggunakan print().
